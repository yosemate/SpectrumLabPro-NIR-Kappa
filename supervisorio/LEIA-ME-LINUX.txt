PARA ABRIR A VERSÃO COMPILADA
Abra SpectrumLabPro_4_17_6 dentro da pasta dist/SpectrumLabPro_4_17_6.
Mantenha a pasta _internal junto do executável. Não precisa instalar Python.

FLUXO DA LEITURA NORMAL (atualizado em 29/10/2026)
O resultado aparece ao terminar a aquisição, antes do recuo do sensor.
Após o recuo, a porta e a gaveta permanecem fechadas. Clique em Nova
Leitura para abrir e trocar a amostra; confirme para iniciar a próxima.
O ensaio de repetibilidade mantém seu fluxo próprio.

PARA RECOMPILAR
1. Extraia este ZIP numa pasta do notebook (não execute dentro do ZIP).
2. Abra um terminal nessa pasta e instale os requisitos do sistema:

sudo apt update
sudo apt install python3 python3-venv python3-dev build-essential binutils libgl1 libegl1 libxkbcommon-x11-0 libxcb-xinerama0 libxcb-icccm4 libxcb-image0 libxcb-keysyms1 libxcb-render-util0 libxcb-randr0 libxcb-xfixes0 libxcb-shape0 libdbus-1-3 libfontconfig1 libx11-xcb1

3. Compile (precisa de internet):

bash compilar_linux.sh

4. Execute:

./dist/SpectrumLabPro_4_17_6/SpectrumLabPro_4_17_6

Mantenha toda a pasta do executável, incluindo _internal. O script também
cria um .tar.gz com o programa completo. Compile na arquitetura do notebook.
Para outro Mint, a compatibilidade depende das bibliotecas do sistema;
compilar no próprio notebook evita diferenças entre sistemas.

USB / ESP32
Se houver erro de permissão na porta serial, execute:
sudo usermod -aG dialout "$USER"
Depois encerre a sessão e entre novamente. As portas no Linux costumam
aparecer como /dev/ttyUSB0 ou /dev/ttyACM0. Selecione a porta detectada.
Wi-Fi usa o endereço do ESP32 e depende do acesso pela rede.
Bluetooth serial exige emparelhamento e uma porta serial configurada no Linux;
a disponibilidade depende do adaptador, do sistema e do firmware.
